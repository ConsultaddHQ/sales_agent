## Issues Found

### P0 — Blocking for production

#### 1. No webhook auth on /search and /product-details
`production-hardening` adds `WEBHOOK_SECRET` + `hmac.compare_digest` (constant-time, no-op when unset). Current branch has zero auth — anyone who knows the ngrok URL can hit either endpoint. Fix exists in a branch but hasn't merged.

**Extra:** once WEBHOOK_SECRET lands, `onboarding-service/main.py:204` (`_do_proxy`) must also forward the `X-TeamPop-Secret` header — it currently passes no auth headers to the search service.

#### 2. CORS still wildcard on both services
- `onboarding-service/main.py:41` — `allow_origins=["*"]`
- `search-service/main.py:118` — `allow_origins=["*"]`

`production-hardening` has `ALLOWED_ORIGINS` env-var driven allowlist on both. Fix exists, not merged.

#### 3. `max_duration_seconds: 600` in current branch
`onboarding-service/elevenlabs_agent.py:805` creates agents with a 600s ElevenLabs server-side limit. `production-hardening` reduced it to 300. Widget enforces 270s client-side, so cost protection exists — but is entirely client-side. If the browser loses the session-end event (navigation, crash), ElevenLabs will run the session up to 10 minutes server-side.

### P1 — Should-have before merging to version/v2

#### 4. Currency hardcoded to ₹ INR
`AvatarWidget.jsx:80`, `656`, `668`, `688` — price formatted as `` `₹${Number(price).toLocaleString("en-IN")}` ``. For a Shopify-first product with mostly non-Indian merchants, this shows the wrong currency symbol. Shopify products carry a currency field that isn't being passed through the pipeline.

#### 5. No rate limiting on `/onboard` and `/submit-request`
Onboarding service has no `slowapi` equivalent. `/onboard` triggers scrape + embed + ElevenLabs agent creation (expensive, slow). `/submit-request` sends email via Resend. Repeat hits burn quota and block pipelines.

#### 6. Missing env vars in search-service .env.example
- `IMAGE_SERVER_URL` — not documented. `shared/config.py:39` defaults to `localhost:8000`, but in single-tunnel setup it must be the ngrok URL or images 404 on every search. Easy to miss during onboarding.
- `OPENROUTER_API_KEY` and `OPENROUTER_MODEL` — still listed but unused since 2026-04-08 price-LLM removal. Misleading.

#### 7. No test suite in current branch
`production-hardening` added `search-service/tests/` — hermetic contract tests (fakes for Supabase + embedder) covering /health, /search, /product-details, UUID validation, truncation, and webhook auth. Current branch has none of this. These tests lock down the search invariants the entire system depends on.

### P2 — Quality / cleanup

#### 8. `local_image_url` dead reference in widget
`AvatarWidget.jsx:812` tries `product.local_image_url` first. But `ProductOut` schema has no `local_image_url` field — the search service already resolves local path into `image_url` at serialization (`search-service/main.py:427`). The widget check always falls through silently. Dead code from an older field name.

#### 9. Large commented-out block in search service
`search-service/main.py:226-250` — 25 lines of commented-out OpenRouter price-parsing code. The price LLM was removed in the 2026-04-08 decision. `max_price` is always `None`. Should be removed or replaced with a one-line TODO.

#### 10. Request-ID log correlation missing from current branch
`production-hardening` adds `contextvars`-based request-ID injected into every log line (read from `X-Request-ID` forwarded by proxy). Without it, tracing a single voice turn across two services requires timestamp matching.

#### 11. AvatarWidget.jsx is 1,146 lines, 44 hook calls
Works correctly, but the inactivity logic alone spans 5 separate `useEffect` blocks. Highest maintenance risk in the codebase. Not urgent, but the next feature added here risks interacting with existing effects.

#### 12. Admin auth is X-Admin-Password plaintext header
No JWT, no session. Acceptable for demo; must upgrade before any public exposure of the admin route.

- No OpenTelemetry / Prometheus — only custom log headers
- No retry / circuit-breaker on ElevenLabs agent creation API calls
- Playwright not in requirements.txt (manual install)
- IMAGE_SERVER_URL must be manually re-pointed after ngrok restart
- ngrok free interstitial blocks widget for external users
- Universal adapter not integration-tested on live sites
- Admin dashboard 422 on process-request (needs investigation)
